# Afnan Aziz — MERN Stack Developer Portfolio
React + Vite + Tailwind CSS + GSAP (ScrollTrigger) + Lenis smooth scroll.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build in /dist

## Replace placeholder content
- `src/data/index.js` — profile, links, WhatsApp, skills, services, projects, experience, testimonials
- Put your photo in `public/` and set `profile.photo`; put your CV in `public/Afnan_Aziz_CV.pdf`
- Project screenshots: set `image` per project (e.g. `/projects/shop.webp`)
